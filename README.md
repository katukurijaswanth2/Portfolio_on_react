## Overview

This portfolio presents my work as a **Full-Stack Java Developer** working with Java, Spring Boot, and React. It is organized the way a recruiter or engineer actually scans a portfolio, and each section answers one question:

<div align="center">

| Who I am | How I got here | What I can do | What I've built | Reach me |
| :---: | :---: | :---: | :---: | :---: |
| [About](https://jaswanthkatukuri4.vercel.app/#about_section) | [Education](https://jaswanthkatukuri4.vercel.app/#growth_section) | [Skills](https://jaswanthkatukuri4.vercel.app/#skills-section) | [Projects](https://jaswanthkatukuri4.vercel.app/#service) | [Contact](https://jaswanthkatukuri4.vercel.app/#contact_section) |

</div>

The design goal is a confident editorial feel: large expressive type, high-contrast dark surfaces, and motion that earns its place. Content and performance come before decoration.

## Design and engineering decisions

<table>
<tr>
<td width="50%" valign="top">

**Type is the main visual**<br />
A heavy display face carries the hero. A clean grotesque handles interface text. A calligraphic script marks the accent words, so hierarchy comes from type, not extra imagery.

</td>
<td width="50%" valign="top">

**A separate mobile hero**<br />
Small screens get a dedicated profile card and slide-in menu instead of a squeezed desktop layout.

</td>
</tr>
<tr>
<td width="50%" valign="top">

**Data drawn as SVG**<br />
The education chart is built with D3 as vector graphics, so it stays sharp at any resolution and each milestone is interactive.

</td>
<td width="50%" valign="top">

**Performance basics**<br />
`preconnect` and `dns-prefetch`, `display=swap` on fonts, native `loading="lazy"`, and WebP for large imagery.

</td>
</tr>
</table>

**SEO and sharing:** semantic sections with anchor IDs, Open Graph and Twitter Card metadata, JSON-LD `Person` schema, canonical URL, theme color `#5c61fb`.

**Accessibility:** `aria-label` on icon-only buttons, `aria-hidden` on decorative SVGs, `rel="noopener noreferrer"` on external links, descriptive `alt` text.

## Getting started

**Requirements:** Node.js 18 or later, and npm, yarn, or pnpm.

```bash
git clone https://github.com/katukurijaswanth2/Portfolio_on_react.git
cd Portfolio_on_react
npm install
npm run dev
```

Production build and local preview:

```bash
npm run build
npm run preview
```

## Deployment

The site is hosted on [Vercel](https://vercel.com). Every push to `main` triggers a production build.

1. Fork this repository.
2. Import it at [vercel.com/new](https://vercel.com/new).
3. Keep the Vite defaults: build command `npm run build`, output directory `dist`.
